Privacy Policy – Verticals Uploader

Last updated: 19 October 2026

Who uses this app

Verticals Uploader is used only by its owner (the onchangetech GitHub account) to publish the owner's own short videos to the owner's own YouTube channel, Instagram account, Facebook Page and LinkedIn profile. It is not offered to the public.

What Google data it accesses

With the owner's consent it uses two YouTube Data API permissions:

  • youtube.upload – to upload videos to the owner's channel;
  • youtube.force-ssl – to add captions to those videos.

It does not read, collect or store any other Google account data, and it does not access data belonging to anyone other than the owner.

Meta (Instagram and Facebook) and LinkedIn data

With the owner's consent it uses Meta permissions to publish Reels to the owner's Instagram professional account and Facebook Page (instagram_basic, instagram_content_publish, pages_show_list, pages_read_engagement, pages_manage_posts, business_management), and LinkedIn permissions to publish posts to the owner's LinkedIn profile (openid, profile, w_member_social). It reads only the IDs needed to post (Page ID, Instagram account ID, LinkedIn member ID). It does not read followers, messages, comments or any other user's data.

How credentials are stored

The access tokens are stored as encrypted GitHub Actions secrets in the owner's private repository and are used only to perform the uploads above. It is never shared with, sold to, or used by any third party.

Viewers

The app collects no information about people who watch the videos. Viewing is governed by YouTube's own privacy policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions (Google), Facebook Settings → Business integrations (Meta), and LinkedIn permitted services.

Data deletion

The app keeps no personal data of its own. To delete what it holds, the owner revokes access as above and deletes the GitHub secrets.

Use of Google API data

Verticals Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
