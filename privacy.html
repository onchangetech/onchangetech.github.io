Privacy Policy – Verticals Uploader

Last updated: 18 October 2026

Who uses this app

Verticals Uploader is used only by its owner (the onchangetech GitHub account) to publish videos to the owner's own YouTube channel. It is not offered to the public.

What Google data it accesses

With the owner's consent it uses two YouTube Data API permissions:

  • youtube.upload – to upload videos to the owner's channel;
  • youtube.force-ssl – to add captions to those videos.

It does not read, collect or store any other Google account data, and it does not access data belonging to anyone other than the owner.

How credentials are stored

The OAuth token is stored as an encrypted GitHub Actions secret in the owner's private repository and is used only to perform the uploads above. It is never shared with, sold to, or used by any third party.

Viewers

The app collects no information about people who watch the videos. Viewing is governed by YouTube's own privacy policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Use of Google API data

Verticals Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
